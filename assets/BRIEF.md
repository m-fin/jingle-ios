## Key features (locked intent)
- Display can turn **off** while sleeping (no bright light in eyes)
- **One alarm**, **no snooze**
- **One-click set time** via radio (WWVB) and/or GPS — confirmed feasible (time from airwaves)
- Default alarm: **6:00 AM**
- Rechargeable battery; same USB-C plug that powers it charges the internal battery
- Looks good and cool
- Sound and volume TBD — including gentle “machine mode” / soothing sleep sounds (“incoming jingle feature noise”)

## Feasibility note
One-click gather time is feasible: US WWVB radio time signals and GPS both broadcast time. Indoor WWVB is usually the practical home-clock path; GPS needs antenna/sky view.
